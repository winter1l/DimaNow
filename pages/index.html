학생이 만든 비공식 앱이에요. 중요한 일정은 학교 공지로 한 번 더 확인해 주세요.

할 수 있는 것

  • 오늘을 한눈에

    다음 수업, 셔틀, 식단, 공지를 홈 한 화면에.

  • 셔틀·4402 남은 시간

    남은 시간과 첫차·막차, 운행 없는 날까지.

  • 학생식당·기숙사 식단

    본관 학생식당과 기숙사 주간 메뉴.

  • 시간표와 학사 일정

    인트라넷에서 가져오고, 휴강·시험 주간도 챙겨요.

  • LMS 할 일 모아 보기

    다가오는 마감과 과제를 과목별로.

  • 기숙사 생활

    상벌점, 외출·외박 신청, 오늘 점호.

  • 장비 대여 현황

    DIMA C 장비가 날짜별로 몇 대 남았는지.

  • 잠금화면 실시간 알림

    곧 시작할 수업과 탈 셔틀을 잠금화면에.

  • 홈 화면 위젯

    앱을 열지 않고 셔틀·식단 확인.

갤럭시에서 설치하기

  1. APK 파일 받기

    위의 APK 내려받기를 눌러요.

  2. 자동 차단 잠시 끄기

    설정 → 보안 및 개인정보 보호 → 자동 차단을 꺼요.

  3. 파일 열고 설치하기

    파일을 열고, 물어보면 출처를 알 수 없는 앱 설치를 허용해요.

  4. 자동 차단 다시 켜기

    설치가 끝나면 자동 차단을 다시 켜요.

업데이트는 앱이 알려 줘요

새 버전이 나오면 홈에서 알려 줘요. 설치는 직접 눌러야 하고, 파일과 서명을 확인한 뒤에만 진행돼요.

예전 버전(v1.x)을 쓰고 있었다면

새 앱으로 따로 설치돼요. 시간표는 설정 → 데이터 관리에서 파일로 옮길 수 있어요.

개인정보는 이렇게 다뤄요

  • 시간표와 위치는 휴대폰 안에서만

    위치 좌표나 이동 기록은 저장하거나 보내지 않아요.

  • 광고·분석 도구가 없어요

  • 학교 계정은 쓰고 싶을 때만

    저장한 계정은 휴대폰 안에서 암호화해요. 학교 로그인 한 구간은 학교가 HTTP를 써요.

  • 사진·신고·문의는 보낼 때만

    식단 사진은 30일 뒤 지우고 메뉴 글자만 공개해요. 글자는 Google Gemini로 읽어요.
