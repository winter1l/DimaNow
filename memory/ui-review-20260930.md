# M3 Expressive UI/UX review — 2026-09-30

Scope: read-only review of the D-093 UI baseline. Evidence: 32 emulator captures (API 36, light/dark/font 1.3; kept in the session scratchpad, not tracked) and a source audit of `ui/DimaNowApp.kt`, `lms/LmsScreen.kt`, `theme/*`, widgets. No code changed. The Courses tab captured black (likely a secure-window flag), so it was reviewed from source only.

Constraints kept: fixed brand scheme (D-027), portrait-only (D-054), D-083 colors, D-093 layout choices. Material3 stable is still 1.4.0 (BOM 2026.03.01 pinned; newest BOM 2026.09.00 also 1.4.0); Expressive APIs exist only in 1.5.0-alpha (observed on Maven, not verified in artifact) — adopting them needs a decision.

## Observed defects (screens)
- Home shuttle capsules break at normal font: the clock wraps one character per line (`2/1/:/5/0`) and `운동장` splits across lines (light and dark). Source: three `weight(1f)` capsules in one Row, DimaNowApp.kt ~968–1028.
- Cold start shows misleading states before data loads: red `셔틀 데이터를 새로고침해 주세요`, `오늘은 제공 식단이 없습니다`, `공지를 확인하고 있어요` — loading is not distinguished from empty/error.
- Background refresh snackbars on every cold start/visit (`625건 저장 완료`, `2026-09-28 주간 식단 저장 완료`) — technical wording and noise.
- Screen headers scroll away (Settings `닫기`, Timetable `수업 추가`); scrolled content shows under the status bar in Settings; three header systems (ScreenColumn row, ScreenScaffold, TopAppBar).
- Campus shuttle shows countdown-then-clock capsules; 4402 shows clock-first `22:00 · 38분 후` pills — inconsistent.
- Closed meal card: muddy gray in light, near-invisible in dark (`lerp(..., Color.Black, 0.12f)`).
- Settings mixes filled pill toggles and outlined segmented rows for the same single-choice role; delete-account confirm is not error-styled.

## Source audit highlights
- ScreenColumn renders each screen as one lazy item (non-lazy content recomposed on minute ticks).
- 73 RoundedCornerShape literals / 10 radii vs 5 theme shape uses; 30 alpha blends; 113 fontWeight overrides with Bold headlines everywhere (flat hierarchy).
- ExpressiveMotion tokens have no call sites; ad-hoc springs/tweens; tab switch double-animates and loses scroll state (`remember`, not saveable).
- Accessibility: timetable chips 30dp high, past times alpha 0.35 (~1.8:1), first/last/next by color only; meal day selector lacks selected semantics; 11sp labels carry data; notice rows ~28dp.
- Timetable term dates typed as text though a DateRangePicker exists; no-class date delete lacks confirm/undo.
- Wording mixes 습니다/해요체; raw error text in snackbars.
- `DimaNavigationShell`, `PermissionStatusRow` unused; DESIGN.md stale vs D-093; DimaNowApp.kt ~3.8k lines.
