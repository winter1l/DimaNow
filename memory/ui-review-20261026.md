# UI/UX review — 2026-10-26 (after D-133)

Scope: read-only review requested by the user ("이처럼 UI UX 부분을 더 바꿀 부분이 있는지 확인해줘") after the PAYCO FAB change. Evidence: 92 captures from a temporary capture test (13 pages, top and scrolled) on the `medium_phone` emulator (1080×2400) in light at font 1.0 and in dark at font 1.3, kept in the session scratchpad, not tracked; plus a source check of each finding. The emulator had no school account and a foreign network, so signed-in pages (수업, 상벌점, 대출, 장비 목록) were seen only in their signed-out or loading states. Checked against `C:\project\ux-guidelines\mobile-ux-guidelines.md` and DESIGN.md. No code changed.

## Observed defects
1. 식단 snackbar covers the FAB (both themes). `MealScreen` draws its `SnackbarHost` in its own Box over the scaffold, so the Scaffold cannot lift the D-133 `PAYCO 식권` FAB above it. ScreenScaffold already takes `snackbarHost` and documents that it keeps snackbars above the FAB.
2. Korean lines break inside words across the app: `확인할 수 있어/요` (Home), `게이트/에 대요` (전체, 도서관), `휴게/실` and `예정이에/요` (기숙사, font 1.3), `안내/해요` (설정). No `lineBreak` is set in the theme; minSdk is 31. Candidate: word-based breaking in the typography (Compose `LineBreak` with phrase word breaks, or `LineBreak.Paragraph` variants); whether Android applies it to Korean on the student's phone is unverified and must be checked on a device before adopting.
3. 캠퍼스 지도 shows `내 위치에서 9089km` on every place when the location is far away (emulator location). `CampusPlaces.kt` and `CampusMapScreen.kt` add the distance whenever a location exists, though the map only draws the student within `CAMPUS_MAP_STUDENT_LIMIT_METERS` (1 km).

## Flow observations
4. Home 식단 card follows the current zone (`useDormitoryMeal = zone == YEIN`): a 예인관 resident off campus or with location off sees `학생식당 · 운영 종료` in the evening while the 기숙사 석식 is open (seen 19:00 KST, home base 엔터관 방향).
5. 수업 sign-in: five caution bullets come before the 학번/비밀번호 fields, so on a phone the fields start near the bottom and the 로그인 button is below the fold (more so at font 1.3).
6. 도서관 and 장비 대여 show only `…불러오는 중이에요` until the school read gives up (silent timeout 60 s, script timeout 30 s in `SchoolServiceHost.kt`); on the emulator neither ended within the ~15 s per page. 도서관 also shows two loading lines at once (loans and hours), where the guide asks for one indicator per group. Not seen on the student's phone.

## Minor
7. 설정 → 앱 업데이트: `업데이트 확인` and `릴리스 보기` are stacked one per row.
