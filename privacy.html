DIMA Now 개인정보 처리방침

DIMA Now(이하 "앱")는 동아방송예술대학교 학생이 개인으로 만든 비공식 Android 앱입니다. 학교가 만들거나 운영하지 않습니다. 이 방침은 앱과 앱이 쓰는 서버(GitHub Pages, Cloudflare Worker, GitHub Actions)가 어떤 정보를 다루는지 설명합니다. 웹 버전은 https://winter1l.github.io/DimaNow/privacy.html에 게시합니다.

시행일: 2026-10-23

1. 운영자가 받지 않는 정보 (기기 안에만 저장)

다음 정보는 사용자의 휴대폰에만 저장되고 운영자나 다른 서버로 보내지 않습니다.

  • 시간표, 학기 기간, 휴강일, 휴강 모드, 특정 날짜 수업 변경
  • 귀가 방향, 알림 방식, 화면 설정, 첫 실행 완료 여부, 위치 테스트 모드
  • 위치: 위치 권한을 허용하면 예인관·본관·원룸촌·4402 정류장 근처인지 기기 안에서만 판정합니다. 좌표나 이동 기록을 저장하거나 보내지 않습니다.
  • 학교 LMS 계정: 자동 로그인을 켠 경우에만 학번·비밀번호를 Android Keystore의 내보낼 수 없는 키(AES-256-GCM)로 암호화해 백업에서 빠지는 영역에 저장합니다. 계정 정보는 학교 공식 로그인 화면(portal.dima.ac.kr, lms.dima.ac.kr)에만 입력됩니다. 저장한 계정은 사용자가 장비 대여·인트라넷 시간표 가져오기·예인관 상벌점·외출·외박 신청 화면을 열거나 버튼을 누를 때 같은 포털 로그인으로 인트라넷·DIMA C에 들어가는 데도 씁니다.
  • LMS에서 받은 수업 목록·공지·과제와 세션 쿠키
  • 학교 인트라넷·DIMA C에서 읽은 정보: 인트라넷 시간표는 미리 보기에서 가져오기를 누른 경우에만 시간표 데이터베이스에 저장됩니다. 예인관 상벌점은 마지막으로 불러온 이번 학기의 합계와 내역(날짜·점수·내용)만 기기 안의 백업에서 빠지는 영역에 저장해 다음에 앱을 열 때 보여 주고, 새로 불러오면 바뀌며 학교 계정을 지우거나 모든 데이터를 지우면 함께 지워집니다. DIMA C 장비 대여 현황은 앱을 닫으면 지워지는 메모리에만 둡니다. 장비 대여 현황에 함께 오는 다른 학생의 학번·대여 사유는 읽는 즉시 버리고 앱에 남기지 않습니다.
  • 카톡 점호 공지(선택): 사용자가 Android '알림 접근'을 허용한 경우에만, 카카오톡 알림 중 '점호'가 들어간 공지를 기기 안에서 읽어(알림 접근을 켜거나 앱을 업데이트한 뒤 알림창에 남아 있는 카카오톡 알림도 한 번 읽어요) 날짜·점호 여부·시각·외출·외박 신청 마감·받은 시각만 백업에서 빠지는 영역에 2주 동안 저장합니다. 카톡 원문, 대화방, 보낸 사람, 다른 알림은 저장하거나 보내지 않습니다. 알림 접근을 끄면 저장한 내용도 지웁니다.
  • 학사 일정 알림: 공개된 학사 일정으로 기기 안에서 만드는 알림이며 계정에 접속하지 않습니다.
  • 셔틀·식단·공지·학사 달력 캐시

Android 백업과 기기 간 이전에는 시간표 데이터베이스와 앱 설정만 포함됩니다. LMS 계정·LMS 캐시·쿠키는 포함되지 않습니다.

  • 식단 사진을 읽는 Google Gemini API는 무료 등급입니다. Google 약관에 따라 Google은 무료 등급으로 받은 사진과 응답을 제품·머신러닝 개선에 쓸 수 있고, 계정과 분리한 상태에서 사람 검토자가 볼 수 있습니다. 사람 얼굴이나 개인정보가 찍힌 사진은 올리지 마세요.
  • 학교 계정은 한 곳에서만 로그인될 수 있어, 앱이 인트라넷·DIMA C에 로그인하면 PC 등 다른 곳의 로그인이 끊길 수 있습니다. 앱은 사용자가 화면을 열거나 버튼을 누를 때만 접속하고, 백그라운드에서 학교 계정에 접속하지 않습니다.
  • 학교 통합 로그인 중 sso.dima.ac.kr:8080 구간은 학교가 암호화하지 않은 HTTP를 씁니다. 공용 Wi-Fi에서는 이 구간의 로그인 정보가 노출될 수 있습니다. 앱은 이 학교 경로 외에는 암호화되지 않은 연결을 허용하지 않습니다.

운영자는 개인정보를 판매하거나 다른 목적으로 제공하지 않습니다. 서비스를 위해 다음 회사의 서비스를 씁니다. 모두 미국 등 국외에 있습니다.

4. 파기

  • 기기 안의 정보: 설정 → 데이터 관리 → 모든 데이터 지우기, 또는 앱 삭제·앱 데이터 삭제로 즉시 지워집니다. LMS 계정은 설정 → 수업 계정에서 따로 지울 수 있습니다.
  • IP 해시: 위 표의 기간이 지나면 정기 작업으로 지웁니다.
  • 올린 사진: 비공개 저장소에서 30일 뒤 자동으로 지웁니다. 더 빨리 지우기를 원하면 아래 연락처로 알려 주세요. Google이 무료 등급 약관에 따라 이미 받은 사본은 운영자가 지울 수 없습니다.

5. 사용자의 권리와 행사 방법

언제든 기기 안의 정보를 직접 열람·수정·삭제할 수 있습니다. 올린 사진·신고 이슈의 삭제나 처리 정지를 요청하려면 아래 연락처로 알려 주세요. 신원 확인에 필요한 최소한의 정보만 요청합니다.

6. 안전성 확보 조치

LMS 계정 암호화(Android Keystore), 로그인 화면 캡처 차단, 앱 로그 미기록, 서버 비밀 값 분리 보관, 업로드 크기·형식·횟수 제한, 데이터 무결성(SHA-256) 확인, 업데이트 파일 서명 확인을 적용합니다.

7. 자동 수집 장치

앱은 광고·분석 SDK를 쓰지 않습니다. 쿠키는 학교 LMS·인트라넷·DIMA C 로그인 세션을 위해 기기 안의 WebView에만 저장되며, 로그아웃하거나 모든 데이터를 지우면 삭제됩니다.

8. 개인정보 보호책임자와 문의

  • 운영자: winter1l (개인 개발자, DIMA 학생)
  • 문의·삭제 요청: 앱의 전체 → 문의·오류 제보, 또는 https://github.com/winter1l/DimaNow/issues (둘 다 공개 이슈로 올라가므로 개인정보는 적지 마세요)
  • 비공개 제보: 저장소의 Security → Report a vulnerability

개인정보 침해 상담은 개인정보침해신고센터(국번 없이 118, privacy.kisa.or.kr)에서도 받을 수 있습니다.

9. 변경

이 방침을 바꾸면 이 문서와 웹 버전을 고치고, 앱 업데이트 안내나 릴리스 노트에 알립니다.
